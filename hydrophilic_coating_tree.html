A｜TPU 基材 UV 光固化塗層
新增 #A1
UV-curing semi-IPN hydrophilic coating for medical guidewires
Ding et al.｜J. Coatings Tech. Res.｜2021
TPU + PUA primer + PVP/PEGDA
DOI Springer
配方架構
PUA（polyurethane acrylate）先固化為 transition layer，再讓 PVP + PEGDA 滲入並 UV 固化，形成 semi-IPN
基材與問題
TPU 鞘覆蓋 nitinol 導線；TPU 與親水層表面能差異大，直接塗覆附著不足
解決策略
PUA 作為過渡層（transition layer）增強附著；PVP 提供潤滑；PEGDA 提供交聯骨架
對本案價值
✦ 最直接參考：TPU + UV semi-IPN 配方框架，PUA primer 思路可轉用於本案 TPU 導管或穿刺針
新增 #A2
Low-friction, high-stability PVP/PEG coated TPU for interventional catheter
ScienceDirect｜Surface & Coatings Technology｜2024
PDA 中間層 + PVP/PEG UV 固化
DOI* ScienceDirect
配方架構
Polydopamine（PDA）在弱鹼環境自聚沉積於 TPU 表面，再以 PDA 作黏著中間層進行 PVP/PEG UV 固化
關鍵結果
水接觸角從 91.3° 降至 28.3°；摩擦係數從 0.4 大幅降低；使用 Irgacure 2959 作光起始劑
PVP 分子量考量
測試 K30（Mn 40,000）與 K90（Mn 130,000），PEG 分子量 400/4000/20,000；逐步優化
對本案價值
✦ PDA 中間層替代 benzophenone primer 的可行方案；分子量優化數據直接可參考
新增 #A3
PVP/PVA coating with high adhesion for coronary guidewires（TPU substrate）
ScienceDirect｜2025
PDA + PVA/PVP/PEGDA UV 固化
ScienceDirect
研究動機
冠狀動脈導線介入中塗層剝落造成不良事件 → 優化 PVA/PVP 塗層製程與附著力
實驗設計
正交實驗優化 PVA、PVP、PEGDA 用量及光起始劑比例；以 TPU 為基材
關鍵發現
PDA 沉積厚度、PVP 分子量與 PEGDA 濃度三者協同影響塗層附著與潤滑性
對本案價值
✦ 最新（2025）正交優化數據；PVA 加入 PVP 體系的附著提升機制可直接借鑒
B｜穿刺針 / 活檢針 親水塗層
新增 #B1
Influence of Biocompatible Hydrophilic Needle Surface Coating on Puncture Biopsy
Gao et al.｜MDPI Coatings｜2020（Open Access）
穿刺針 / FEM 模擬 / 親水潤滑層
DOI MDPI 全文
核心貢獻
建立簡化有限元素穿刺模型（FEM），並以體外穿刺實驗驗證；比較有/無親水超潤滑塗層的穿刺力差異
塗層特性
生物相容性親水超潤滑塗層（biocompatible hydrophilic super-lubrication coating）；降低針與生物軟組織間摩擦力
測試方法
量測摩擦係數；FEM 分析穿刺力 Fx = f(N) 線性關係；in vitro 軟組織穿刺驗證
對本案價值
✦ 唯一直接對穿刺針親水塗層的開放全文；FEM 方法論可用於本案穿刺力評估
新增 #B2
Lubricious echogenic coatings for biopsy needles（Patent WO2007089761A2）
Google Patents｜2007（公開全文）
活檢針 / 親水潤滑 + 超音波回聲
Google Patents
塗層功能
同時提供親水潤滑（lubricious）與超音波回聲（echogenic）雙功能；適用於 biopsy needle、trocar、catheter
塗層架構
先塗親水高分子層，再覆回聲結構層；或兩者整合為單一塗層；回聲微粒嵌入潤滑層
針型範圍
骨髓活檢針、乳腺定位針、軟組織活檢針（16G/18G，10–20 cm）、BIO-PINCE 儀器用針
對本案價值
✦ 活檢針親水塗層專利；claims 結構與塗層 durability 要求可參考
C｜熱固化 isocyanate / PVP 系統（經典基準）
經典 #C1
Hydrophilic coating（isocyanate + PVP 熱固化）
US4666437｜最早雙層熱固化系統
熱固化 / isocyanate crosslink
USPTO PDF
製程
第一層：isocyanate（≥2 NCO groups）有機溶劑液乾燥；第二層：PVP 溶液浸塗；含水氣高溫固化形成 urea crosslink
缺點（後代改良起點）
雙層步驟難以精確控制 primer/PVP 比例；primer 可能部分溶入第二層；需額外烘乾設備與時間
對本案價值
✦ 熱固化基準：本案若評估 UV vs 熱固化，需了解此基準系統的瓶頸
經典 #C2
Lubricious hydrogel coatings（US5160790）
單步熱固化 crosslinked PVP
1-step 熱固化 / crosslinked PVP
USPTO PDF
改良點
單步製程；isocyanate 與 PVP 混合在同一配方，烘烤後交聯固定；解決雙層步驟比例控制問題
IPN 結構
crosslinked 系統比簡單 PVP blend 更緊密固定，耐磨、耐溶劑；PVP 不易遷移
對本案價值
✦ 單步 isocyanate 熱固化路徑：若 UV 設備有限，此為備用方案參考
D｜Benzophenone anchor + UV photografting 機制
既有 #45
Photoreactive Polymers Bearing Zwitterionic Phosphorylcholine for Surface Modification
Lin, Fukazawa, Ishihara｜ACS AMI｜2015
BP + MPC / C–H insertion
DOI PubMed
機制
合成含 benzophenone（MHPBP）與 MPC 兩性離子的共聚物（PMH）；UV 照射後 BP 以 C–H 抽氫方式共價固定於基材表面，最大吸收 254 nm / 289 nm
性能
高親水性、抗蛋白吸附、抗細菌沾附；適用多種材料表面（包含 TPU）
對本案價值
✦ 核心機制文獻：BP anchor + MPC 雙功能設計是本案 Plan B 配方最直接的理論基礎
新增 #D2
UV cure topcoatings for medical devices（US12037560B2）
Google Patents｜2024（公開全文）
4-Methacryloxy-benzophenone + HEAA/AA UV topcoat
Google Patents
光活性單體
4-Methacryloxy-2-hydroxy benzophenone（MHB）與 HEAA（N-2-hydroxyethyl acrylamide）及 Acrylic Acid 共聚，形成親水光活性高分子
性能規格
lubricity <25 gf；durability <50 gf（Harland FTS pinch test）；可單獨作 topcoat 或與非光活性親水高分子混合
固化條件
UV 固化；光強度（mW/cm²）與 IPA 比例影響潤滑性與耐久性；可配合 basecoat 使用
對本案價值
✦ 最新 UV topcoat 專利（2024）：benzophenone 衍生物 + 極性 acrylate 共聚物路徑，claims 可作迴避設計參考
E｜光起始劑選型（水溶性、生醫、UV固化）
既有 #53
Water-Soluble Photoinitiators in Biomedical Applications
Tomal, Ortyl｜Polymers｜2020（Open Access）
光起始劑選型 / Type I & II
DOI MDPI 全文
Type I（均裂）代表
Irgacure 2959（I2959）：高水溶性、低毒性、生醫最常用；320–365 nm；殘留風險低
Type II（抽氫）代表
Benzophenone：需共起始劑（tertiary amine）；用於 C–H insertion 表面固定，非自由基聚合
選型準則
高水溶性（生醫配方）、低細胞毒性（ISO 10993）、可見光相容性（低能量 LED）、避免黃變
對本案價值
✦ I2959 為本案 UV 固化配方首選光起始劑；BP 適用於 primer photografting 層
F｜PVP 光降解風險與 UV 劑量視窗
既有 #59
Photooxidation of poly(N-vinylpyrrolidone) in solid state and aqueous solution
Hassouna et al.｜Polym. Degrad. Stab.｜2009
PVP 光降解 / UV dose 上限
DOI
降解機制
UV 照射導致 PVP 主鏈氧化裂解；固態與水溶液中均會發生；過高 UV dose 使 PVP 分子量下降、親水性劣化
劑量視窗
存在最佳 UV 劑量範圍：足夠固化但不過度氧化 PVP；須平衡交聯效率與降解風險
對本案價值
✦ 設計 UV 固化製程時必讀：UV 劑量不是越高越好，需建立 dose-lubricity 曲線
